FocusGuard

An on-device focus detector. It watches head pose, gaze, phone presence and window context through a regular webcam, fuses them in a decision tree, and tells you when you have been distracted longer than you chose to allow.

Try the live demo View the code

The demo runs entirely in your browser. No video is uploaded or stored.

How it works

Every tick the app builds one feature vector from all of its signals and passes it through a single decision tree that outputs focused or distracted plus a short reason. That one decision drives the alert, instead of several separate threshold checks.

CameraHead pitch and yaw from facial landmarks, iris offset within the eyes, eye openness, and whether a face is visible at all.
ContextWhether your task window is in front, how often you switch, how long you have been on the current one, and keyboard and mouse idle time.
PhoneA separate, independently trained EfficientDet object detector looking only for a cell phone.

The thresholds are not fixed in advance. Calibration watches you work normally for ten seconds and sets your neutral head pose from the median of that baseline and your look-away thresholds from its spread, so someone who sits very still gets tighter thresholds than someone who fidgets. A leaky score smooths the per-tick verdict, so one noisy frame never raises an alert.

What the browser version can and cannot see

The desktop app reads signals from Windows itself. A web page cannot, and pretending otherwise would misstate what the demo measures. Six of the twelve features are identical, five are honest substitutes, and one is impossible.

The features that need cross-person validation — the camera ones — are exactly the ones that run identically. The substituted signals do not depend on a person's face, so they are not what leave-one-person-out is testing.

Run the full version

The desktop app is Windows-only and reads signals a browser cannot. It processes frames in RAM and never writes them to disk.

# Windows PowerShell
git clone https://github.com/Nivaan0803/Focus-Guard
cd Focus-Guard
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py

Limits

Looking away is a proxy, not a measurement of attention. It can misclassify note-taking, legitimate breaks, accessibility-related movement, and off-screen work. It is built for voluntary self-management, never surveillance or discipline. Phone detection has its own separate failure modes — dark scenes, glare, an obscured or face-down phone — and those errors do not carry into the gaze and pose figures.
